# Booki - Site de location immobilière

## Description

Booki est un site de location immobilière permettant aux utilisateurs de rechercher des hébergements et des activités dans la ville de leur choix. Ce projet consiste en l'intégration statique complète de la maquette de la page d'accueil fournie par l'équipe design.


## Objectifs du projet

- Intégrer une maquette responsive en HTML et CSS
- Garantir une largeur minimale de 320px pour le responsive

## Technologies utilisées

- HTML5 : Structure sémantique
- CSS3 : Mise en page et responsive design
- Git & GitHub : Versionnement et hébergement

## Responsive Design

Le site est entièrement responsive et s'adapte à trois breakpoints principaux :

- Desktop : > 1024px
- Tablette : 768px - 1024px
- Mobile : 320px - 767px
